# 帧解析功能使用指导

> 适用版本：v1.4.7（2026-09-26 整理）。
> 本文按「当前版本实际行为」编写，所有描述以源码为准（`src/SerialTool.Core/Framing/` + `MainViewModel.cs`），
> 文末附「已知限制清单」——读完可直接在上面标注你想改的点。

---

## 1. 功能定位与数据链路

帧解析把串口/TCP 收到的**原始字节流**按「协议模板」切分成一帧一帧的结构化数据，用于替代肉眼看 HEX 流。整体链路：

```
字节流到达 ──┬─ 时序图（逐位方波，与解析无关，始终工作）
             └─ 帧解析引擎（勾选「启用」后接管）──┬─ 接收区：按帧行显示（✓/✗）
                                                  ├─ 字段曲线：从数据域取值画曲线（仅成功帧）
                                                  └─ 自动应答：命中规则自动回发（仅成功帧）
```

**关键行为：勾选「启用」后，接收区不再显示原始字节流，只显示解出的帧（含错误帧 ✗）。**
取消勾选即恢复原始显示；但解析期间收到的字节不会补显回原始流。

主窗顶部「帧解析 · 接收显示」组：

4. 勾选「启用」，观察 8 个剧情的输出与状态栏 帧✓/✗ 计数。

## 3. 帧结构模型：模板如何描述一帧

一帧 = **帧头 + 字段链（按序） + 校验域 + 帧尾**。字段链放在帧头之后、校验域之前，顺序任意组合：

```
┌──────┬────────────── 字段链（按序） ──────────────┬────────┬──────┐
│ 帧头  │ cmd / fixed / length / data（任意排列）      │ 校验域  │ 帧尾 │
└──────┴───────────────────────────────────────────┴────────┴──────┘
```

### 3.1 四种字段类型

| 类型 | 字节数 | 说明 |
|---|---|---|
| `cmd` 命令域 | 1~4 | 显示时用 `\|\|` 括出；字段曲线/自动应答可按命令前缀过滤。帧里没有命令就别加 |
| `fixed` 固定域 | 1~4 | 占位不解释，如 Modbus 的起始地址+寄存器数量（4 字节） |
| `length` 长度域 | 1~4 | 值 = **数据域字节数**。可选大端/小端。**至多一个** |
| `data` 数据域 | — | **至多一个**。长度由三种方式之一决定（见下） |

### 3.2 数据域长度的三种决定方式

| 方式 | 配置 | 适用 |
|---|---|---|
| ① 长度域 | 字段链里放一个 `length` | 协议帧里有长度字节（如 Modbus 响应的 byteCount） |
| ② 定长 | `data` 的「定长」列填字节数 | 固定长度帧（如 Modbus 03 请求恒 8 字节，data 定长 0） |
| ③ 帧尾扫描 | `data` 勾「扫描帧尾」+ 模板配帧尾 | 无长度域、靠帧尾界定（数据域里出现帧尾字节会自动逐位置重试校验） |

> 无长度域时，数据域必须定长或扫描帧尾，否则模板保存不通过。

### 3.3 校验域与帧尾

- **算法**：`none` / `xor` / `sum8` / `crc8` / `crc16Modbus` / `crc16Ccitt` / `crc32`；
- **覆盖范围**：帧头首字节 → 校验域前一字节的**全部字节**（固定，不可自定义起点）；
- **校验字节序**：指**你的协议线上**是高字节在前（CRCh CRCl）还是低字节在前（Modbus 标准）。
  与算法默认序（Modbus=低在前，CCITT/CRC32=高在前）不同时会自动反转再比对；
- **帧尾**：HEX，可空。仅「帧尾扫描」模式必须配；配了帧尾则成帧时校验帧尾字节。
- **帧长上限**（16~4096，默认 512）：防假帧头导致无限等待——长度域值或推算总长超限即判假帧头。

## 4. 模板编辑器

「模板…」按钮打开。**「保存并关闭」才生效**：逐模板强校验 → 写入 `Config/frame_templates.json`（exe 同目录）→ 热重建解析器，无需断开连接。「取消」回滚到打开时的快照。

### 4.1 界面布局

- **左列 模板列表**：`●` = 启用解析（参与并行仲裁）；新增 / 删除。
- **右列 模板字段**：名称、启用解析勾选框、帧头、帧尾、校验算法、校验字节序、帧长上限；
  下方字段链表格（加字段 / 删字段），列：类型 / 字节数(cmd/fixed/length) / 大端(长度域) / 定长(data) / 扫描帧尾(data)。

### 4.2 保存时的强校验规则

| 规则 |
|---|
| 帧头必须 ≥1 字节合法 HEX |
| 帧尾须为合法 HEX（可空） |
| 字段链不能为空；长度域、数据域各至多一个 |
| 字段类型只能是 cmd / fixed / length / data |
| cmd / fixed / length 字节数须 1~4 |
| 帧尾扫描模式必须配帧尾 |
| 无长度域时数据域须定长（≥0）或扫描帧尾 |
| 帧长上限须 16~4096 |

非法模板会弹窗指出原因并定位到该模板，保存中止。若正在解析时模板集合非法（如手改 JSON），勾选「启用」会被自动弹回并在状态栏显示原因。

### 4.3 持久化与迁移

- 路径：`<exe目录>\Config\frame_templates.json`，JSON 数组，可直接手改（改坏单项会被跳过）；
- 首次启动无配置时自动生成 4 个内置示例模板（全部默认启用）；
- v1 老格式模板（lengthBytes/cmdBytes 模型）读取时自动迁移为 v2 字段链。

## 5. 接收区的帧行显示

解析开启后每帧一行，格式（以 Modbus 读响应为例）：

```
[14:23:05.117] ✓ [Modbus 读响应(03) 长度域] 01 |03 02| 12 34 | B5 33
 └─ 时间戳(可关)  └─ ✓成功/✗失败  └─ 来源模板名      │  │    │      └ 校验+帧尾
                                                   │  │    └ 数据域
                                                   │  └ 命令域起到数据域止（命令+长度/固定域）
                                                   └ 帧头及命令域之前的字节
```

错误帧在行尾追加原因：

```
[14:23:06.220] ✗ [Modbus 读响应(03) 长度域] 01 |03 02| 12 34 | 00 00   ← 校验错误(期望 B5 33 实际 00 00)
```

要点：

- 帧行**始终按 HEX 显示**，不受「HEX 显示」开关影响；「时间戳」开关有效；
- 颜色：数据行与帧行（✓/✗）可在接收显示组设置不同颜色；
- 状态栏实时统计：`帧✓ n / ✗ m`；
- 过滤：对接收区生效，**按帧原始字节**匹配（HEX 子串忽略大小写与分隔符，或显示文本子串）；日志文件与数据缓冲始终全量；
- 日志文件写入与显示同格式的帧行；
- 时序图（图表窗口第一页）不受解析开关影响，始终按波特率逐位重建。

## 6. 解析引擎行为细节

### 6.1 多模板并行仲裁

解析集合 = **所有勾选「启用解析」的模板**（顶部下拉框选中的那个不产生筛选作用）。每收到一段字节，引擎让全部启用模板各尝试一次：

| 情形 | 结果 |
|---|---|
| 某模板「结构完整 **且** 校验通过」 | 立即成帧输出 ✓。**模板列表顺序 = 优先级**，排前的赢 |
| 全部结构完整但校验都失败 | 按列表顺序取第一个输出为 ✗ 错误帧（真坏帧不被其他模板误吞） |
| 结构匹配但字节不足（半包） | 缓存等待后续字节（滞留超 4096 字节开始逐字节丢弃兜底） |
| 全部结构不匹配 | 丢弃到只剩「最短帧头长度−1」字节，等下一个可能的帧头 |

- **帧头不同的模板天然分流**；帧头相同的模板靠「长度结构 + 校验」区分（如内置的 Modbus 读/写模板同为 `01` 帧头）；
- 错误帧按其结构声明的长度**整体消费**——若长度域本身被干扰切错长度，可能连带吞掉后续字节，靠下一帧帧头重新同步。

### 6.2 粘包 / 半包 / 杂波

| 场景 | 引擎行为 |
|---|---|
| 粘包（多帧一次到达） | 连续切分，逐帧输出 |
| 半包（一帧拆多段到达） | 内部缓冲拼接，凑齐才成帧 |
| 帧前杂波 | 帧头之前的字节静默丢弃（计入内部丢弃计数，界面不显示） |
| 假帧头（数据里恰好出现帧头字节） | 长度/结构超限即回退重搜下一个帧头 |
| 完全无关的字节流 | RX 计数照涨，接收区无输出（保留帧头前缀以防跨界帧头） |

### 6.3 模板变更时机

**切换模板/编辑保存只对之后收到的数据生效**——解析器重建时清空缓冲，历史字节不会回溯重解析。

## 7. 联动功能 A：字段曲线（图表窗口第二页）

入口：主窗「波形」按钮打开图表窗口 → 「字段曲线」页签（窗口右上 `?` 有内置说明）。

**数据来源：仅解析判定成功的帧**（✗ 帧不采样；未开解析则无数据）。

配置项（底部表格，改动即存 `Config/field_plots.json`）：

| 列 | 说明 |
|---|---|
| 启用 | 行级开关 |
| 名称 | 图例名（**图例暂不能渲染中文，建议英文**） |
| 模板 | 限定来源模板名，空 = 任意 |
| 命令HEX | 只采样命令域以此前缀开头的帧，空 = 不过滤 |
| 偏移 / 宽度 | 从**数据域**第 N 字节起取 1 / 2 / 4 字节 |
| 大端 / 符号 | 多字节值的字节序与有无符号解释 |
| 缩放 / 单位 | y = 原始值 × 缩放；单位拼在图例名后 |

- X 轴 = 时间（秒，本次连接起点计）；「跟随最新」锁定最近 60 秒，取消后可滚轮缩放、拖动平移；
- 偏移+宽度越出数据域的帧跳过该曲线（不报错）；
- 点数有上限，超限自动裁剪旧点。

## 8. 联动功能 B：自动应答（右侧面板「自动应答」页签）

用途：模拟对端设备——收到匹配的**成功帧**后，延迟自动回发一帧。需先开启帧解析。

匹配条件（三者同时配置取**与**，均可留空 = 不限）：

| 条件 | 说明 |
|---|---|
| 模板 | 限定来源模板名 |
| 命令域前缀 | HEX，如 `03` |
| 帧内任意子串 | HEX，对整帧原始字节搜索 |

动作参数：

| 参数 | 说明 |
|---|---|
| 回复帧 | 命中后发送的完整帧 HEX（空/非法 = 规则不生效） |
| 延迟 ms | 0 = 尽快；调度粒度 50ms |
| 仅一次 | 首次命中后自动禁用并持久化（适合握手类指令） |

- 每帧只取**第一条**命中的规则，回发一条；
- 回发在接收区以 `⇄` 前缀回显，区别于手动发送 `→`；
- 命中计数列实时统计；配置存 `Config/auto_reply.json`。

## 9. 内置示例模板解读（默认 4 个）

| 模板 | 帧布局 | 用途 |
|---|---|---|
| Modbus 读请求(03) 定长 | `01` + cmd1 + fixed4 + data(定长0) + CRC | 主机→从机的读请求，恒 8 字节 |
| Modbus 写请求(10) 长度域在帧中间 | `01` + cmd1 + fixed4 + **len1** + data + CRC | 展示长度域不在帧头后的写请求 |
| Modbus 读响应(03) 长度域 | `01` + cmd1 + **len1** + data + CRC | 从机响应，byteCount 定数据长 |
| EM 协议 帧尾扫描 | `EA` + fixed2 + cmd1 + data(→扫描`ED`) + CRC + 帧尾`ED` | 无长度域协议；数据域内嵌 `ED` 也能正确切分 |

> ⚠ 这 4 个模板的「校验字节序」出厂均为**高字节在前**。Modbus 标准线上序是**低字节在前**——接标准 Modbus 设备（或跑 §2.2 脚本）前请先改为「低字节在前 (Modbus 标准)」，否则每帧都报校验错误。

自定义示例——`AA 55` 帧头、无命令、数据域 4 字节定长、无校验、无帧尾：

```
帧头: AA 55    字段链: data(定长 4)    校验: none    帧尾: (空)
```

## 10. 排障速查

| 现象 | 可能原因 → 动作 |
|---|---|
| 勾「启用」后状态栏提示「没有启用的模板」 | 编辑器里没有任何模板勾「启用解析」→ 去勾选 |
| 接收区无输出，但 RX 计数在涨 | ① 帧头配错（最常见）→ 核对线上的帧头字节；② 半包滞留 → 确认对端发完整帧；③ 全是无关杂波 → 正常（帧头前缀之外全丢弃） |
| **每帧都 ✗ 校验错误** | ① 字节序反了 → 改「低/高字节在前」（Modbus 标准为低在前）；② 算法选错；③ 帧头选了数据中常变的字节导致切错位 → 加长帧头 |
| ✗ 帧尾不匹配 | 帧尾字节配错；或帧尾扫描模式数据里含帧尾且校验也对不上 → 核对 CRC 与帧尾定义 |
| 偶发 ✗ / 帧错位 | 通信误码（波特率/线路）；假帧头（数据中偶现帧头序列）→ 考虑更长帧头 |
| 同一帧总被另一个模板抢走 | 模板列表顺序 = 优先级 → 把目标模板排前；或加长帧头天然分流 |
| 改了模板没反应 | 模板变更只对新数据生效，历史不重解析；确认编辑器点了「保存并关闭」 |
| 字段曲线无点 | ① 有没有 ✗ 帧（只采样成功帧）；② 模板/命令过滤条件对不上；③ 偏移+宽度越出数据域；④ 宽度不是 1/2/4 |
| 自动应答不回 | ① 帧解析没开 / 帧是 ✗；② 回复帧 HEX 空/非法；③ 规则被禁用（检查「仅一次」是否已触发过——触发后自动禁用） |

## 11. 当前已知限制清单（供优化讨论）

1. **解析与原始显示互斥**：开解析就看不到原始字节流，无「双视图/带内切换」；解析期间的原始数据不落显示缓冲。
2. **顶部模板下拉作用有限**：仅查看与触发解析器重建，不筛选解析目标（易误解为「选中谁就解析谁」）。
3. **丢弃字节数不可见**：杂波/假帧头/滞留裁剪都计入内部 `DroppedBytes`，UI 无任何呈现，流里丢了多少字节无从得知。
4. **帧行只有 HEX 视图**：不受「HEX 显示」开关影响；数据域没有数值解释（浮点/字符串/按寄存器拆字），也没有点击单帧看详情/字段表的交互。
5. **校验范围固定**：恒为帧头首字节→校验域前，不能排除帧头、不能自定义起始偏移。
6. **长度域语义固定为「数据域字节数」**：总帧长语义、寄存器字数语义（Modbus 03 请求的 quantity）表达不了，只能靠定长绕（内置模板正是这么做的）。
7. **内置模板出厂字节序与 Modbus 标准相反**（高在前 vs 标准低在前），首次接标准设备必踩坑（本文 §9 ⚠ 与脚本文档均有提醒）。
8. **帧时间戳 = 成帧时刻**：半包帧的时间戳是最后一字节到达后的时刻，非首字节时刻；且为软件时钟。
9. **无暂停/单步/重放**：不能停流检查缓冲、不能对历史字节换模板重解析。
10. **字段曲线图例不支持中文**（ScottPlot 字体限制，页签 `?` 帮助里有说明）。
11. **多帧显示行不可交互**：不能按模板/成功失败快速过滤统计，只有全局字节级过滤。
